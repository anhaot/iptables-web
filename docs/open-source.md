# 开源范围与验证

源码仓库使用根目录的 [MIT 许可证](../LICENSE)。公开内容包括中心与 Agent 源码、前端及嵌入资源、测试、构建和安装脚本、systemd 模板、CI 工作流、用户文档与开发交接文档。

## 文件与发布包边界

- 源码分支不包含运行数据、账户与密码哈希、主机清单、密钥、身份私钥、审计、真实防火墙备份、环境配置、构建产物或浏览器输出。
- 个人面试稿与本地笔记仅保留本地，由 Git 忽略规则排除；不要使用强制添加绕过忽略规则。
- 环境模板仅包含示例地址和配置项，不包含真实凭据。截图使用隔离的开发后端和演示数据；Docker 映射采用演示响应，避免公开本机真实容器信息。
- 发布包只复制构建脚本列出的公开文档，不再自动收集目录内所有 Markdown。双二进制和校验和作为 GitHub Releases 附件分发，不提交源码分支。
- 不将运行目录、历史备份或整个工作目录压缩后上传 GitHub。

`python3 scripts/check-source.py` 检查 Git 已跟踪文件和未忽略的新文件，拒绝常见私有文件路径，验证 Markdown 本地链接、章节锚点和明确的源码引用。构建发布包和 CI 均运行此检查；它不是完整的凭据扫描器，公开前仍需检查新增内容、图片与提交历史。

## 功能检查范围

| 范围 | 验证方法 |
| --- | --- |
| 规则 CRUD、排序、启停、Docker 批量、备份恢复与失败补偿 | Go API、执行器、存储与变更管理测试 |
| 登录、强制改密、账户锁定/重置、动态密钥、逐主机与主机组授权 | Go 认证、路由、用户和密钥测试 |
| 签名登记、审批生命周期、加密凭据、心跳与连接并发 | Go 纳管和主机存储测试、隔离中心/Agent HTTP 烟测 |
| 在线检测缓存、继承设置、搜索、Docker 分组及旧 Agent 错误 | Go 监控测试及前端逻辑回归 |
| 安装卸载、路径校验、双二进制发布 | Shell 语法、隔离路径回归、构建与离线验包 |
| 桌面页面与权限展示 | 1440×1000 浏览器验收；只使用隔离数据和开发后端 |
| 文档与公开文件 | 本地链接、锚点、源码引用、文件边界与凭据扫描 |

完整开发命令见[贡献指南](../CONTRIBUTING.md)，产品决策和继续开发要求见[开发交接](development-handoff.md)。

开发后端和模拟外部命令不能证明真实内核、防火墙发行版或 Docker 网络在生产中的行为。当前验证不包含真实远程主机的规则变更、真实 systemd 升级或网络命名空间测试；上线前需在专用测试机按[部署验收](deployment.md#12-部署验收清单)检查。不宣称经过形式化验证、渗透测试或全平台兼容认证。
