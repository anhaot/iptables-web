# 路线图

## 当前能力

- Web 管理只操作 packet 后端；
- firewalld 保持外部管理，不重新引入 Zone 编辑页面；
- Docker IPv4 映射可直接创建规则；
- Docker IPv6 映射已分类展示，当前只读；
- 规则助手保留 iptables/ip6tables/nftables/firewalld 生成与解读；
- 经授权的变更可记录实际操作者、导出脱敏审计详情，最近一次规则变更可限时回滚；
- 默认管理员、管理员新建/安全重置及密码过期账号强制改密；
- 预编译包、手动安装、完整导出和干净卸载可独立使用；
- 支持轻量 Agent 二进制、主动签名申请、单个/批量审批、HTTP/HTTPS 回连验证、自动凭据交换、中心加密凭据、主机详情导航、用户按单台/主机组授权和逐主机隔离的批量规则创建；
- Agent 安装与卸载脚本可独立使用；卸载只删除带所有权注释的 Agent 规则；
- 管理员可配置密码复杂度、密码历史、改密字符差异、有效期、失败锁定方式、账户重置默认密码及验证码大小写策略；验证码固定混合大小写字母和数字。
- 普通用户既可逐台授权中心本机/远程主机，也可通过主机组动态继承当前和未来远程成员；授权后拥有完整逐主机防火墙权限。
- 纳管概览按主机逐行默认收起并可展开规则摘要；规则助手作为全局工具放在侧栏。

## 规划中

1. 为托管规则模型加入明确的地址族，安全接入 ip6tables CRUD 与排序。
2. 将当前“Agent 主动申请、控制端回连管理”扩展为跨 NAT 的 Agent 长连接、细粒度角色、版本化策略和金丝雀发布。
3. 增加真实网络命名空间集成测试，但测试必须隔离，不能修改开发机现有防火墙。
4. 在现有逐台 HTTPS/Nginx 部署范例基础上，逐步迁移到 `HttpOnly + Secure + SameSite` Cookie 会话。
5. 为审计文件补充轮转、远程汇聚和防篡改能力。
