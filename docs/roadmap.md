# 路线图

## 2026-07-28 审查状态

本轮已经关闭的 P0 / P2：

1. 移除规则表单的废弃 `zone` 字段，恢复手工新增、编辑和 Docker“添加阻止规则”。
2. `go.mod` 固定 Go 1.26.0 / toolchain 1.26.5，并跑通标准测试、race 和 vet。
3. 修正登录页后端文案，补充公开 favicon。
4. 增加规则保存前差异预览、持久化管理员审计、完整导出和 10 分钟回滚窗口。
5. 通过真实浏览器验证规则创建、审计记录、双确认回滚和回滚后规则状态。

当前稳定边界：

- Web 管理只操作 packet 后端；
- firewalld 保持外部管理，不重新引入 Zone 编辑页面；
- Docker IPv4 映射可直接创建规则；
- Docker IPv6 映射已分类展示，当前只读；
- 规则助手保留 iptables/ip6tables/nftables/firewalld 生成与解读；
- 管理员变更可审计、导出，最近一次规则变更可限时回滚；
- 预编译包、手动安装、完整导出和干净卸载可独立使用。

后续优先项：

1. 为托管规则模型加入明确的地址族，安全接入 ip6tables CRUD 与排序。
2. 增加真实网络命名空间集成测试，但测试必须隔离，不能修改开发机现有防火墙。
3. 将固定初始密码改为一次性初始化流程并强制首次登录改密。
4. 提供 HTTPS 反向代理范例，并逐步迁移到 `HttpOnly + Secure + SameSite` Cookie 会话。
5. 为审计文件补充轮转、远程汇聚和防篡改能力。
